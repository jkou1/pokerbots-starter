# prettygoodpoker

AC2 project generated by `ac2 project init`. Defines an agent, environment,
grader, starter dataset, and runnable SDK configs.

## Setup

```bash
ac2 login
uv sync
cp .env.example .env   # set OPENAI_API_KEY
```

## Run

From inside this folder

```bash
uv run python upload_dataset.py
uv run python -m prettygoodpoker.eval
uv run python -m prettygoodpoker.train
```

Runtime dependencies belong in `[project].dependencies` in `pyproject.toml`
